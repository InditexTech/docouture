== Build collaborative whiteboard applications

[feature-tabs]
====
[feature,label="UI-agnostic"]
--
image::feature-1.png[A Weave.js canvas rendered through several UI frameworks]
image::feature-1-dark.png[role=dark]

Change the UI using our included primitives or build a new one. With Weave.js,
you get a unified system that includes a high-performance, fully customizable
whiteboard so you can focus on building the product.

[.cta]
xref:main:architecture.adoc[Learn more]
--

[feature,label="Powerful abstractions"]
--
image::feature-2.png[The store, node, plugin and action layers of a Weave.js room]
image::feature-2-dark.png[role=dark]

Keep what you need, discard the rest, and build your own. Stores handle the
real-time sync complexity while nodes, plugins, and actions allow for
selection, drawing, erasing, creating geometric shapes, and perfect freehand
drawing to smooth development.

[.cta]
xref:main:build/index.adoc[Learn more]
--
====

= Introduction

Welcome. This is the starter site: the smallest complete Antora component,
here to be copied rather than read.

== What is here

* `antora-playbook.yml` — build configuration; start editing there.
* `docs/antora.yml` — declares this component's name and version.
* `docs/modules/ROOT/nav.adoc` — the navigation tree.
* `docs/modules/ROOT/pages/` — the pages themselves.

Continue to xref:getting-started.adoc[Getting started].

Key features

  • Scaffold in one command
  • Themed with the IOP Design System
  • Diagrams and search, built in
  • AI-ready docs

docouture new lays down a full Antora site — content tree, GitHub workflows, an AGENTS.md briefing for coding agents — into an existing repository. docouture dev, docouture build and docouture publish take it from there.

Try it

The UI bundle is a themed fork of Antora’s own default UI: dark/light mode, a version switcher, full-text search, and a set of authoring blocks — tabs, cards, accordions, feature tabs — with no plain AsciiDoc equivalent.

See the UI bundle

Mermaid/PlantUML/BPMN/Excalidraw diagrams render via a self-hosted Kroki service, code blocks get build-time Shiki highlighting, and a full-text search index ships with every build — all with zero configuration beyond what docouture new already wrote.

See what ships

Every build publishes llms.txt/llms-full.txt for LLM ingestion, and npx skills add InditexTech/docouture installs a set of agent skills that plan, scaffold and keep a site’s content in sync with the repo it documents.

See the skills

Free & open source

The CLI, the Antora/https://asciidoctor.org[Asciidoctor] extensions and the release tooling are Apache-2.0. The UI bundle itself is themed with Inditex’s proprietary IOP Design System, which makes a site built with it internal-only for now — see the FAQ below for the full story.

View the repository

Frequently asked questions

What is docouture?

An Antora documentation platform: a themed UI bundle (IOP Design System), a set of Antora/Asciidoctor extensions, and the docouture CLI that scaffolds, serves, builds and publishes a site built on top of them. See About.

How do I create a new site?

npx @inditextech/docouture-cli new <name> — see Quickstart.

Can documentation be versioned?

Yes — standalone (stable + prerelease) or versioned (full release history). See Versioning modes.

Is docouture open source?

The CLI and extensions are Apache-2.0, but the UI bundle depends on a proprietary design system — see the full FAQ for the details.

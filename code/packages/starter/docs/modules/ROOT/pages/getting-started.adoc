= Getting started

== Add a page

Create an AsciiDoc file under `modules/ROOT/pages/`, then add it to
`modules/ROOT/nav.adoc` so it appears in the navigation:

[,asciidoc]
----
* xref:my-new-page.adoc[My new page]
----

A page that is not listed in the navigation is still published; it just cannot
be reached by browsing.

== Build the site

[,console]
----
$ pnpm nx run @inditextech/pdocs-starter:build
----

The generated site is written to `build/site`.

TIP: While working on the UI itself, run `pnpm nx run @inditextech/pdocs-ui-bundle:preview`
instead. It serves a sample page with live reload and does not require a full
site build.

== Page hero

Every page gets a hero — breadcrumbs, title, and whatever of the following page
attributes it sets — above its content:

[,asciidoc]
----
= Page Title
:description: Shown as the hero excerpt AND as <meta name="description">.
:page-tags: Beta, Internal
:page-action: Get started
:page-action-url: getting-started.adoc
:page-action-secondary: View source
:page-action-secondary-url: https://github.com/…
----

`description` is the only one this page itself sets (see the page source). All
five are optional, and each action attribute pair (`page-action` +
`page-action-url`, or the `-secondary` pair) only renders when BOTH halves are
present — a button that goes nowhere is worse than no button. `*-url` accepts
either a page reference (`getting-started.adoc`) or a literal URL.

To suppress the hero entirely on a page — a landing page, say — set
`:page-role: -hero`. The page's title then renders as a normal in-article
`<h1>` instead.

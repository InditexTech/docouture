= Adding a page

Create an https://asciidoc.org[AsciiDoc] file under a module's `pages/` directory, then
add it to that module's `nav.adoc` so it's reachable:

[,asciidoc]
----
* xref:my-new-page.adoc[My new page]
----

A page not listed in `nav.adoc` still builds and publishes at its own URL — it's just
unreachable by browsing, and gets no breadcrumbs/previous-next pagination.

== Group without a page of its own

A bare list item with no `xref:` starts a new, unlinked heading in the side menu —
this is how xref:main:modifying-the-navigation.adoc[]'s section grouping works, and how
this site's own `main:nav.adoc` groups Overview/Getting started/Guides/Reference/etc.:

[,asciidoc]
----
* Getting started
* xref:main:prerequisites.adoc[Prerequisites]
* xref:main:quickstart.adoc[Quickstart]
----

Same page (`home.adoc`), same hero (`home-hero.hbs`, unchanged) and the same
content-column conventions, but with `:page-layout: home-single` instead of
`home`: the hero renders as a full-width block above the content rather than
a sticky aside beside it, at every breakpoint rather than only below `s`. See
home-single.css for what actually changes — a handful of column/stickiness
overrides, nothing about the hero or block markup itself.

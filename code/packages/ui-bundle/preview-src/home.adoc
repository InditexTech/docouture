== Supported features

Blocks on this page come from Asciidoctor extensions rather than from the
layout, so a landing stays authored content. Until those extensions land
(GH-20 through GH-23) any AsciiDoc renders here, which is what this section is
for: it checks that the block's heading row, its dashed rule and the gaps
around its body are right regardless of what fills it.

* A plain list, to check body rhythm inside a block.
* A second item.
* A third.

== Key features

Each `==` section is one block: a heading row in `title/m` over a dashed 4/4
rule, then the block's body. The gap between blocks is 72 at `l` and `m`, 64 at
`s` and 56 at `xs`; the gap inside one is 40 at `l` and 32 everywhere else.

== Get started

The final block sits 80 above the site footer at every breakpoint. The footer
itself is the landing's own — four columns, dashed rule above, no
previous/next and no feedback row, since a landing is not a page in a reading
sequence.

== How this page works

Each `==` heading opens a block: the heading row and its dashed rule come from
the layout, the block's body is ordinary AsciiDoc. The column beside this one is
the hero — the name comes from this page's own title, and the chips and buttons
from the `:page-tags:` and `:page-action*:` attributes at the top of this file.
Set `product_logo` under `site.keys` in `antora-playbook.yml` to put a product
mark above the name, and add `:page-hero-image:` (or `:page-hero-video:`) to put
a still or a video below them.

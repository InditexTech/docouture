= Setup a favicon

The browser tab icon is a `site.keys.favicon` value in `antora-playbook.yml`, served
from a file under `ui.supplemental_files`:

[,yaml]
----
site:
  keys:
    favicon: /_/favicon.ico

ui:
  supplemental_files: ./supplemental-ui
----

`docouture new` already wires this up with a placeholder — replace
`docs/supplemental-ui/favicon.ico` with a real one, same filename, and rebuild. The
`/_/` prefix is the UI bundle's own output directory (`ui.output_dir`, default `_`),
not the site root — supplemental files land there, which is why the key isn't just
`/favicon.ico`.

== Using a different filename

Rename the file under `supplemental-ui/` and update `site.keys.favicon` to match — the
path is a literal, not a convention https://antora.org[Antora] infers.

== Removing it entirely

Delete the `favicon` key (and the file, if nothing else in `supplemental-ui/`
references it) — the UI bundle falls back to no favicon rather than failing the build.

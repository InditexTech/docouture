= v5.0.0
:description: This version delivers new diagramming capabilities, including group element editing, shape labels, and polygon support, alongside an alpha server-side document API. This release also improves performance and reliability with enhanced persistence, asynchronous store connections, and several fixes to drawing and text editing behavior.

== Metadata

* *Release date*: 2026-06-18

=== Added

* https://github.com/InditexTech/weavejs/issues/1039[#1039] Allow editing individual elements inside a group without ungrouping
* https://github.com/InditexTech/weavejs/issues/1080[#1080] [alpha] API to manipulate document state natively on server-side
* https://github.com/InditexTech/weavejs/issues/1101[#1101] Add inline text labels to shape nodes (Rectangle and Ellipse)
* https://github.com/InditexTech/weavejs/issues/1104[#1104] Add Polygon Node and Polygon Drawing Tool with Label Support
* https://github.com/InditexTech/weavejs/issues/1106[#1106] Add y-indexeddb client-side persistence to WeaveStoreAzureWebPubsub for optimistic initial render

=== Changed

* https://github.com/InditexTech/weavejs/issues/1089[#1089] Refactor Image node and tools to avoid saving image fallback on the state
* https://github.com/InditexTech/weavejs/issues/1090[#1090] Remove usage of @syncedstore/core
* https://github.com/InditexTech/weavejs/issues/1091[#1091] Make Store Connection Lifecycle Asynchronous and Increase Azure Web PubSub Frame Size to 512 KB

=== Fixed

* https://github.com/InditexTech/weavejs/issues/1088[#1088] Is not possible to draw a dot or very small line in the canvas using the brush tool
* https://github.com/InditexTech/weavejs/issues/1098[#1098] WeaveTextNode: textarea edit overlay misaligns due to hardcoded border offset and scrollHeight approximation

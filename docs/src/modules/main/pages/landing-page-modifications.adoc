= Landing page modifications

The landing page (`ROOT/pages/index.adoc`) is the one page rendered through the UI
bundle's `home` layout (`:page-layout: home`). Its section order is fixed — each block
is optional, but present blocks appear in this order:

. *Hero* — the page's own header attributes: `:description:`, `:page-tags:`,
  `:page-action:`/`:page-action-url:` (primary button), `:page-action-secondary:`/
  `:page-action-secondary-url:` (secondary button), `:page-hero-image:`/
  `:page-hero-image-alt:`.
. *Get started* — a `[cards]` block, typically 4 entry points.
. *Key features* — a `[feature-tabs]` block, a handful of capability slides.
. *A CTA* — a `[cta]` block, one pitch plus one action.
. *FAQ* — an `[accordion]` block.

`:page-nav-module: main` is what gives the landing page a side menu at all — `ROOT`
itself has no `nav.adoc`, so it borrows whichever module this attribute names.

Every block above is documented in full, with real syntax, in
xref:main:custom-asciidoc-components.adoc[] — this page is the *section order*
pattern, not the block reference.

== Replacing the placeholder images

`ROOT/images/{hero,card,feature,feature-dark}-placeholder.png` are stand-ins. Replace
them with real artwork under the same filenames (or update the `image::` references to
new ones) — they're a separate concern from the *site* logo/favicon, which
xref:main:setup-the-product-logo.adoc[] and xref:main:setup-a-favicon.adoc[] cover.

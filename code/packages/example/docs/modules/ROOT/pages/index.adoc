Weave.js is a framework for building visual collaborative applications: a
headless canvas engine, a React integration and a choice of transports, so a
team can draw, edit and reason on the same surface at the same time.

== Stores

A store is how a room's state reaches every participant. Pick the transport
that matches where the application runs.

[cards]
====
xref:store-websockets:index.adoc[Websockets Store]:: WebSockets as transport, client and server.
xref:store-azure-web-pubsub:index.adoc[Azure Web PubSub Store]:: Azure Web PubSub as transport, for deployments already on Azure.
xref:store-standalone:index.adoc[Standalone Store]:: No transport at all — render a canvas straight from room data.
====

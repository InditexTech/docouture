= Overview

This package is the destination for migrating an existing documentation site
from Fumadocs to Antora. It is wired up and building, but has no real content
yet.

== Why it exists now

Keeping the package in the build from the start means the workspace graph, the
UI bundle dependency and CI all exercise a second consumer of the UI — so the
migration begins against a pipeline that is already known to work, rather than
standing one up under time pressure.

== What migration will involve

* Converting MDX pages to AsciiDoc, including the JSX components Fumadocs
  allows inside content.
* Mapping the existing navigation to `nav.adoc`.
* Preserving published URLs, or providing redirects where they must change.

Until then, the `starter` package documents the minimal setup.
